# Verilog HDL Learning

This repository contains my learning journey in **Verilog HDL**, starting from basic digital logic and progressing toward RTL design.

## 🎯 Learning Goals

* Learn Verilog HDL from the fundamentals
* Understand combinational and sequential logic
* Practice writing synthesizable RTL
* Learn simulation and testbench development
* Build digital design projects
* Develop a strong foundation for VLSI/RTL design

## 📚 Topics

* Verilog Basics
* Logic Gates
* Combinational Circuits
* Sequential Circuits
* Flip-Flops
* Registers
* Counters
* Finite State Machines
* Memory
* RTL Design
* Testbenches
* Digital Design Projects
